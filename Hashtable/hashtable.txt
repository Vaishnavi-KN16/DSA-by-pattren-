2. finding duplicates 
int[] arr = {1,2,3,1,4,2};

HashSet<Integer> set = new HashSet<>();

for(int num : arr){
    if(set.contains(num)){
        System.out.println("Duplicate: " + num);
    }
    set.add(num);
}
Use HashSet when:

✅ You need unique elements

✅ You need fast searching

✅ You need to detect duplicates

✅ You need fast insertions and deletions
Don't use it when:

❌ You need elements in a specific order

❌ You need indexing like get(0)

❌ You need duplicate values


import java.util.HashSet;

class Solution {
    public int removeDuplicates(int[] nums) {
        HashSet<Integer> set = new HashSet<>(nums);
        return set;
        
    }
}
